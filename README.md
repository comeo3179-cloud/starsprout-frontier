# 星芽：荒原行动 · STARSPROUT FRONTIER

一款俯视角射击与探索生存游戏。手动走位、瞄准和射击，在三张战区地图中完成守点、拆毁或护送任务，最终击败双阶段裂隙守卫。

2.4「战区异变」：三地图分别出现孢子喷发、地脉热浪、霜脉冰爆，可将普通敌人引入险区。三位首领使用不同招式与造型：裂隙守卫、熔炉监工、霜棘猎手。HUD 显示当前杀招、躲避提示与弱点暴露；冰缓持续 2 秒，冲刺不受影响。该版本的机制与浏览器验收已完成。

2.3「三境远征」：营地可选荒原边境（信标防线）、赤焰熔炉（反应堆拆毁）、霜线远征（冰原护送）。新增熔核榴弹与回旋刃，各有专属武器改造、弹道、视觉与音效。暂停页可返回营地换图。该版本已完成机制与桌面、手机视口验收。

2.2「相位收割」：冲刺给敌人留下紫色印记，射击触发连锁爆破；冲刺掠过敌弹蓄能，满能量按 F 开启 7 秒无限弹药暴走。手机在双摇杆之间提供暴走快捷按钮。该版本已更新并完成验收。

2.1「遗迹远征」的三条可选支线、两种敌人和三件战术遗物仍然保留。打开战术地图追踪紫色终端，完成回收、追猎或虫巢清剿后返回领奖。

## 开始游玩

在线试玩，无需安装：<https://comeo3179-cloud.github.io/starsprout-frontier/>

双击 `index.html` 即可离线游玩；所有图形和音效均在本地生成，无需下载素材或安装依赖。

也可使用已安装的 Node.js：

```sh
npm start
```

打开 <http://127.0.0.1:4173/>。服务只监听本机；按 Ctrl+C 停止服务。桌面键鼠操作体验最佳，触屏设备提供左右双摇杆。

## 内容与操作

- 三张各 3200 × 2400 的地图，拥有独立出生、主线、补给与支线位置，熔炉工业设施及冰原护送路线。
- 五种随时可切换的武器：日耀步枪、霰星散弹、离子穿透炮、熔核榴弹、回旋刃，独立弹匣和装填计时。榴弹碰撞或引信到期爆炸；回旋刃飞出并追向玩家返回，去返每个目标各命中一次。
- 四类普通敌人，以及双阶段 Boss。远程敌人会寻找清晰射线后锁定瞄准；冲锋、震地和 Boss 弹幕都有预警。坦克与 Boss 出招后的恢复期会暴露弱点。
- 升级时三选一，共 **17 种成长协议**：12 种可叠加强化，以及五种单次武器改造——步枪连锁电弧、霰弹震荡击退、轨道弹首次命中爆破、榴弹范围提升、回旋刃回程增伤。前几级优先提供武器改造选项。
- 荒原边境的三座信标可自行选择探索次序，每座在光圈内累计坚守 **40 秒、分三个阶段**。回声站侧重虫群与冲锋，棱镜站侧重远程交叉火力，潮汐站侧重重装围攻。离圈暂停上传并保留进度；全部连接后出现最终 Boss。
- 补给箱免费开启，医疗和武器工坊消耗芯片。每座信标完成后直接获得 **60 经验、30 芯片、恢复 35 生命**，并迎来短暂补给间隙。
- 战术地图显示信标、补给、医疗和工坊，可选择追踪目标，战场箭头与距离提示会同步更新。

| 操作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 瞄准、射击 | 鼠标瞄准，按住左键 | 拖动右摇杆 |
| 闪避冲刺 | 方向键 + Shift / 空格，立即向输入方向冲刺 | 推动左摇杆并点击冲刺按钮 |
| 脉冲伤害与打断 | Q | 脉冲按钮 |
| 星核暴走 | 满能量按 F | 满能量后点击双摇杆之间的暴走按钮 |
| 切换武器 | 1 / 2 / 3 / 4 / 5 | 点击武器卡 |
| 装填 / 精准装填 | R 开始装填；绿色窗口内再按 R | 装填按钮；绿色窗口内再次点击 |
| 开箱、设施、信标 | 靠近后按 E | 交互按钮 |
| 战术地图 | M / Tab；选择信标后返回，M / Esc 关闭 | 顶部地图按钮或小地图下方入口 |
| 暂停 | P / Esc | 顶部暂停按钮 |

备用弹药不限；空弹匣持续射击会自动装填，装填期间仍可移动。**在装填进度 52%–72% 的绿色窗口内第二次按 R，立即完成精准装填，当前弹匣伤害增加 15%。** 每次装填只能尝试一次；提前或错过只会失去该次奖励，普通装填仍会完成，连按或切枪不能刷新机会。

冲刺具有短暂无敌；未输入方向时沿最近移动方向冲刺。脉冲可以清除附近敌弹并打断蓄力或冲锋。打开地图、操作指南或切到其他窗口时，进行中的战斗会暂停。

小屏触控支持左右双摇杆、换枪、冲刺、脉冲、交互与精准装填按钮；支持横竖屏布局和游戏全屏。顶部可开关音效；在“操作指南”中可切换 **“画面反馈：舒缓”**，减少震屏、冲刺残影和动态摆动，首次使用也会读取系统的减少动态效果偏好。

这是可从开场玩到 Boss 结局的本地单局版本。探索补给、选择路线和不同构筑会改变节奏，熟练直推可以在几分钟内完成；目前没有将单局强制拉长为 10–15 分钟，也未用自动仿真时长代替真人游玩时长。

## 保存与旧版

本版保存个人最高分、音效与画面反馈偏好，以及是否关闭过行动提示；不保存进行中的关卡，刷新后从新局开始。存储仅在当前浏览器本地，不同浏览器或打开方式的数据互不共享。

原来的“滑动合成＋塔防”版本保存在 [garden.html](garden.html)，也可从新版页面下方进入。

## 验证

```sh
npm test
```

**100 项逻辑测试：动作版 85 项，旧合成版 15 项。** 包含移动与碰撞、武器与成长、支线与遗物、相位印记与有限连锁、掠弹、星核暴走及终局和重置边界。

可复跑正常输入的固定种子整局仿真：

```sh
node scripts/simulate-expedition.js --seeds 20 --seconds 600
node scripts/simulate-expedition.js --build mods --seeds 20 --seconds 600
```

脚本使用移动、射击、装填与交互等玩家操作，不修改血量或跳过目标。需要说明的是，机器人会读取公开地图并精确瞄准，其通关率与耗时不等同于真人数据，逻辑计时也不代表包含绘图和音效的帧率。

界面已进行桌面键鼠与手机尺寸检查。战斗体验与难度仍可随实际游玩反馈继续调整。

## 仓库范围

本仓库只包含游戏源码、测试与本地开发服务器。开发过程中的 QA 报告、浏览器截图、仿真记录、打包脚本与网页发布包不在仓库内，游戏本身不依赖它们：

- 游戏运行只需要本仓库根部列出的 HTML、JavaScript 与 CSS，不含任何第三方运行时依赖。
- `npm test` 运行 `tests/*.test.js`，只依赖 Node.js 内置的 `node:test`。
- `tests/` 中的 UI 夹具与 `render-benchmark.html` 需要 Playwright 才能自动驱动，本仓库不含该依赖，可忽略。
