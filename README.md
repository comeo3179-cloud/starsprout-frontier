# 星芽：荒原行动 · STARSPROUT FRONTIER

一款俯视角射击与探索生存游戏。手动走位、瞄准和射击，在五张战区地图中完成守点、拆毁、护送、引雷或星火转运任务，最终击败各战区的双阶段首领。

7.2.1「按需说明」：营地介绍和模式卡缩为短标签，地图长简报、玩法原理及保存说明默认收起。鼠标移到“ⓘ 说明”展开，移出自动收回；点击固定，再点或 Esc 收起。手机点按查看，键盘 Enter / Space 切换。关键风险数字和装置、升级效果保留可见；战斗减少重复教学通知。

7.2.0「撤离抉择」：西侧接应保持 10 秒但周围空旷，东侧等待 16 秒并有三块完整岩石遮挡弹道，两处都在圈内累计 3 秒登舰，地图提前显示取舍。每局按种子生成一件黑匣子：带回额外 480 分，携带时六种武器新发射弹丸伤害增加 15%，不减速；每 12 秒广播位置、增加 6 警戒并招来最多两名追兵，待生成的黑匣子追兵最多四名。G 或任务面板的“弃货”按钮可随时放下，停止新广播并失去武器加成，已来的追兵保留；重拾保留广播倒计时。样本与黑匣子都须登舰才能结算，死亡失去未结算货物，地图、暂停和升级选择期间全部计时冻结。不新增账号永久收益。

7.1.0「操控与视野」：战斗提示出现、变长或布局变化后，世界标签在下一绘制帧避开当前面板；固定尺寸的生命、弹药和经验变化只检查所属面板，摇杆与准星内部动画不触发全量测量。桌面通知固定竖向位置并在结束时立即隐藏，保留淡入，避免滑动和淡出尾部盖住标签。手机保持双摇杆时，第三指抬起即可选择升级、遗物、战术模块和地图追踪目标，滑动或取消不会误选，恢复战斗清除旧触点的移动与射击。修复运输无人机的不可执行提示抢占附近补给箱，以及回收区超载重甲震地攻击漏算 12% 难度增幅；原有普通任务、试炼、连续远征与星海远航规则保留。

7.0.0「危险回收」：新增独立的连续回收区，五处有限来源分布在工业货道、采样荒坡和电容废场。保险箱可用近距离 EMP 获得四秒静默窗口，也可射击破锁；钻探在工作圈内累计八秒，离圈保留进度；运输无人机需要射击截停再亲自回收货物。警戒只随明确行动上涨，跨档增援只触发一次，巡逻、钻探与接应增援均有有限配额和十四名存活上限。两个接应点可自由选择，呼叫后十秒来舰、圈内累计三秒登舰，期间仍可移动、射击、换弹与换枪。只有带回的样本才以每点八十分结算；死亡丢失携带物，空手也能安全撤回，不要求清场或强制终局首领。保留 6.0 环境反制与原有武器成长，沿用同种子重试、手机多指与个人账号，不新增永久经济或进行中云存档。

6.0.0「破阵生态」：星海远航第三至第六段加入三类可反制敌人。棱盾卫正面减伤，绕背、射击后的开盾窗口与 EMP 都能突破；破岩兽锁定直线冲锋，诱导撞岩可令其眩晕并承受额外伤害；投雷工兵留下独立感应雷，移出预警、射爆或 EMP 接管皆可应对。电容筒爆炸会伤害双方，接管后不伤玩家；碎裂掩体能真正被破坏，打开弹道与通路，新爆炸仍尊重爆破前的掩体遮挡。每房最多两名新敌人替换原配额，首两段与终局保持原有入门节奏。营地菜单压缩为模式卡与工具行，破阵资料只在准备或暂停时展开，不增加战斗文字面板。三种远航环境的原生配乐也有了不同声部与节奏。

5.0.1「试玩校准」：普通阶段横幅移至顶部，默认显示 1.2 秒、最多 1.6 秒；任务详情可展开或收起，始终保留当前目标与完成数。首次教学按实际移动射击、冲刺、精准装填依次出现，各地图另附一句目标说明。霜线未启动的锁定护送段不计作教学完成；已有教学完成档案与手动关闭偏好继续有效。中央成就宣告保留。发布状态以验收和部署记录为准。

5.0.0「星海远航」：新增独立七段模式，六间作战房间有清剿、共鸣破阵、星尘收割三种目标，以及星海碎岛、日冕船坞、镜海深域三种环境。目标完成后亲自进入撤离星门，安全选下一条常规或高风险航路；第七段挑战三阶段「航界吞星者」。开局六选一起装，三槽装置可逐段替换，组成星门猎场、交叉镜海或反向潮汐三个动作共鸣。保留六把武器、局内升级与进化，房间间自动回收已获得的掉落、少量治疗并补弹，芯片可购买一次整备。新增本地 Web Audio 原创配乐，按探索、战斗与首领切换；操作指南可单独关音乐，总声音开关控制全部声音。沿用手机双摇杆、横屏和多指换弹/换枪；新菜单只在安全整备中展开。普通与过载难度、可输入种子和同种子再航，不新增账号永久属性或战斗存档。发布状态以验收与部署记录为准。

4.0.0「归星织网」：新增归星遗址的三枚星火转运主线与归星守墓者。携带时仍能移动射击、换枪、装填和 EMP，成功冲刺将星火放在起点，回收后继续；追踪轰击锁定旧位置，可以引敌借势清场。第六把星索钉枪在敌人、岩石或射程终点落钉，两钉无遮挡则成绊线；移动引敌穿线造成一次截击与短暂减速。新改造星索电容延长线寿命，新进化双极星桥增加同时布线上限，并有限清除敌弹。地图、军械、连续远征路线和手机军械栏同步扩展。

3.1.0「流派觉醒」：连续远征第一幕完成后，每个流派二选一觉醒，随构筑带入第二战区和中枢决战。游击先锋选择折返跃迁或滑步快装；精准猎手选择弹仓接力或破招标定；脉冲织者选择随行电场或蓄势脉冲。沿用冲刺、换弹、换枪和 EMP 按钮，选定后本局不能改选；暂停页可查看详细规则。

3.0.0「连续远征」：新增三幕模式，自选第一战区、突破后从未探索战区中选择第二站，最后进入独立竞技场「裂隙中枢」。开局选择游击先锋、精准猎手或脉冲织者，分别围绕移动射击、精准装填、EMP 构筑。等级、武器进化、升级、遗物、战术、芯片跨图保留；两次关间整备可选修复、火力或机动补给。第二站绑定迅猎、装甲或增援危机；终章击破双锚可永久解除中枢主宰的 65% 减伤，再应对光栅、三重坍缩与环弹。保留单区行动、六波试炼、个人成就和手机横屏多指操作，不新增账号存档字段；线上版本以实际部署记录为准。

2.10.1「提示稳定性修复」：修复未追踪裂隙任务时，左侧「行动提示」随 HUD 刷新反复显隐的问题。提示稳定显示，暂停、完成教学或主动关闭时仍按原规则隐藏。

## 开始游玩

腾讯云在线试玩，无需安装：<https://starsprout-playtest-d7bqa2fc8da1-1494842646.tcloudbaseapp.com/>。账号功能连接该站点的腾讯云环境；自行部署请配置自己的认证环境及授权域名。

双击 `index.html` 即可离线游客游玩；图形和音效在本地生成。账号与云存档需要网络、已配置的腾讯云环境和授权的网页域名；本地开发不具备云端域名授权时仍可试玩。

也可使用已安装的 Node.js：

```sh
npm start
```

打开 <http://127.0.0.1:4173/>。服务只监听本机；按 Ctrl+C 停止服务。桌面键鼠操作体验最佳，触屏设备提供左右双摇杆。

手机推荐在营地点击「横屏游玩」，横置设备后开始。浏览器允许时会进入系统全屏并请求横屏；不支持时使用占满浏览器视口的沉浸布局。若画面未旋转，请关闭手机的竖屏锁定或开启自动旋转；网页不能在所有手机上强制改变屏幕方向。点击「退出全屏 / 退出沉浸」可恢复普通页面。

## 内容与操作

- 星海远航的清剿房使用有限配额；共鸣破阵需要击毁三座各 260 生命的共鸣柱，卫兵仍会追击；星尘收割有三座各需四格的收割器，附近 185 范围内击杀充两格，远处击杀给最近未满收割器一格，不会因在错误地点击杀而无法完成。完成后入口附近的出口点亮，按 E / 点交互撤离，目标完成后存活追兵仍有威胁。
- 六件装置围绕已有操作：星尾推进器留下冲刺尾流、越界猎针强化冲刺后的下一次射击；镜匣校准仪追加精准装填镜弹、悬停棱镜在脚下留下短暂镜台；潮汐引擎留下固定引力井、极光电池强化 EMP 后的三次实际射击。每次实际射击只触发一次装置，散弹不会逐弹丸重复触发，辅助弹仍被岩石阻挡。三槽最多激活一对共鸣，也可混搭三个系列。
- 共鸣动作：星门猎场在冲刺后的射击同时塌缩现存尾流；交叉镜海从精准装填留下的镜台沿当前准星方向形成额外火线，鼓励离开原站位再射击；反向潮汐允许引力井存在期间再次按 Q / 点脉冲引爆，保留原冷却，不重复清弹或刷新极光电池。

备用弹药不限；空弹匣持续射击会自动装填，装填期间仍可移动。**在装填进度 52%–72% 的绿色窗口内第二次按 R，立即完成精准装填，当前弹匣伤害增加 15%（连续远征的精准猎手为 50%）。** 每次装填只能尝试一次；提前或错过只会失去该次奖励，普通装填仍会完成，连按或切枪不能刷新机会。

冲刺具有短暂无敌；未输入方向时沿最近移动方向冲刺。脉冲可以清除附近敌弹并打断蓄力或冲锋。打开地图、操作指南或切到其他窗口时，进行中的战斗会暂停。

冲刺冷却即将结束时，可以提前轻按一次；会保留按下时的方向，冷却结束后执行。打开菜单、暂停或失焦会取消这次排队。装备榴弹时的虚线表示按当前障碍和敌人位置估计的爆点，移动目标可能改变实际命中；出界弹丸消失，不会爆炸。虚线范围会随“熔核扩散”改造扩大。

小屏触控支持左右双摇杆、换枪、冲刺、脉冲、交互与精准装填按钮；支持横竖屏布局和游戏全屏。顶部可开关音效；在“操作指南”中可切换 **“画面反馈：舒缓”**，减少震屏、冲刺残影和动态摆动，首次使用也会读取系统的减少动态效果偏好。

这是可从开场玩到 Boss 结局的本地单局版本。探索补给、选择路线和不同构筑会改变节奏，熟练直推可以在几分钟内完成；目前没有将单局强制拉长为 10–15 分钟，也未用自动仿真时长代替真人游玩时长。

## 保存与旧版

登录账号后，隐藏成就、最高分、试炼胜场/最快纪录/最远波次和教程状态保存在该账号下，并在联网时同步。首次发现的中央宣告只针对当前玩家尚未发现的技巧；下载已发现成就不会重复宣告。试炼按每局唯一编号去重，刷新、重试或重看战报不会重复计胜场。

游客档案仅保存在当前浏览器。登录后可以选择“这些是我的进度”，主动认领该浏览器的旧存档；同一份存档只能认领一次，不会自动交给每个登录账号。共用设备请先确认归属。清理浏览器数据会移除游客档案及尚未上传的记录；云端确认成功的存档可再次登录恢复。音效和画面偏好仍按设备保存。不保存进行中的关卡，刷新后从新局开始。

账号认证使用官方 CloudBase SDK，密码由托管认证服务处理。客户端不含管理员凭据；数据库只能经校验当前身份的接口读写。此设计提供玩家隔离、合并及请求去重，不能防止客户端修改个人成绩；当前没有公共排行榜。后端结构、迁移与独立数据库测试见 [云存档接口说明](cloudbase/PROGRESS_CONTRACT.md)。本地自托管 SDK 及其许可证位于 `vendor/`，加载时无需国外 CDN。

原来的“滑动合成＋塔防”版本保存在 [garden.html](garden.html)，也可从新版页面下方进入。

`node scripts/check-salvage-runs.cjs` 使用原始属性和普通玩家动作运行回收策略，保存成功、空返或失败。`check-salvage-browser-run.cjs` 使用实际绘图与音效、原生动画帧运行一局，支持 `--seed 2 --policy deep --difficulty normal`。`check-salvage-mobile-run.cjs --difficulty normal --seed 2` 全程用真实 CDP 双摇杆和第三指驱动战斗，不替换引擎输入；`--difficulty overload` 改用横屏超载，保留自然死亡。`check-salvage-ui.cjs` 检查准备、追踪、暂停与结算；`check-salvage-touch.cjs` 检查持双摇杆时的第三指动作及菜单返回；`check-salvage-risk.cjs --release` 检查八种横竖屏/普通全屏携货布局、多指弃货、旋转暂停恢复、双路接应及无人机取货，带有显式边界夹具；`check-salvage-account.cjs --failures` 用独立账号替身检查离线重试和切换身份，完全不写真实后端。`check-salvage-layouts.cjs` 用独立几何抽查 256 种布局的目标与运输路线连通，再以原始属性移动检查边界种子；这是无敌人布局夹具，不代表通关或全部种子保证。具体夹具和输入边界见各脚本开头及输出报告。

`node scripts/check-mobile-layout.cjs` 进一步验证手机横竖屏、全屏、旋转和菜单，使用浏览器触点切换全部六把武器，检查满能量时的控件遮挡及交互按钮尺寸。部分脚本的 `--release` / `--online` 模式另外依赖本机打包清单；该清单不随源码分发，克隆仓库后请使用默认源码模式。

`node scripts/check-awakening-ui.cjs` 验证六技巧实际触发、中央宣告的冻结/队列/输入隔离、存储、静音、舒缓画面、手机档案，以及试炼入口到结算的界面闭环。旧入口 `check-secret-techniques.cjs` 保留兼容。试炼界面用例中的加速夹具不用于平衡结论；`tests/trials.test.js` 另有只使用正常玩家操作的九局通关验证。

`node scripts/check-encounter-ui.cjs` 检查裂隙介绍、追踪、计时暂停、失败、奖励与觉醒/升级队列、单槽模块和手机菜单，并使用原始角色属性与正常操作完成三种挑战。`node scripts/check-encounter-renderer.cjs` 验证真实 Canvas 的节点、提示、失败与模块效果；其受控场景只用于绘图验收。`node scripts/check-touch-actions.cjs` 使用浏览器真实多触点输入，检查持摇杆时换弹、换枪、技能以及三种新模块的触发。

`node scripts/benchmark-engine.cjs <基准提交>` 可对比基准提交与当前引擎的 CPU 耗时；默认基准为 HEAD。它使用受控压力场景，不代表游戏整体帧率。

`node scripts/check-evolution-ui.cjs` 验证五种进化升级选择、暂停说明、领悟与升级叠加、旋转和多指操作；加 `--public-only` 使用原始角色属性和真实动画帧自然获取进化。`node scripts/check-evolution-renderer.cjs` 检查进化弹体、余震预告和舒缓画面。`node scripts/check-evolution-runs.cjs` 通过正常玩家操作分别取得五种进化并运行至胜负，不修改角色属性；这些固定种子机器人结果用于机制闭环验证，不代表真人胜率。
